# 从经营结构到可测试动作

## 1. 建立可比基线

优先选择同市场、同品类和接近价格带的店铺；品牌店与分销店、跨境与本土模式分别解释。对标差异写明，不用原始 GMV 排名代表经营效率。

用同口径完整周期计算 `ΔGMV = 本期GMV - 基期GMV`，基期大于零才计算增长率。同时报告绝对量，低基数高增长不自动进入优先级首位。若用户只要静态研究，直接交付结构而无需硬造历史增长叙事。

## 2. 区分存量结构与增量贡献

- 当前商品/渠道份额回答“现在依赖谁”；两期差值回答“增长来自谁”。两者分表。
- 商品贡献 `Δ_i = 本期_i - 基期_i`；其对店铺增长的贡献百分点为 `100 × Δ_i / 基期店铺GMV`。只有基期店铺 GMV 大于零时计算。
- 可另报 `Δ_i / Δ店铺GMV`，注明其是净变化贡献比例：总变化接近零时不报；有抵消时允许负值或超过 100%，不要裁剪。
- 每个视角单独对账：`剩余变化 = 店铺总变化 - 已知分项变化之和`。有未覆盖商品时称“未覆盖/未解释变化”；不能直接称“其他商品贡献”，因为其中也可能有时间、估算或定义差异。
- 无基期分项值时不把缺失补零。没有可比历史则不计算贡献，只展示当前结构与待验证线索。
- Top1/Top3 份额必须使用同窗总 GMV；只拿到列表子集时明确分母为样本，不包装成全店集中度。达人/内容归因可重复时不计算合计份额。

例：店铺从 100 增到 130，商品 A 从 20 增到 40，可归属的变化为 +20，对店铺增长贡献 +20 个百分点。其当前份额 40/130 不能替代这个计算；余下 +10 是否来自其他商品须看覆盖与对账。

## 3. 检查增长机制

| 假设 | 最小支持证据 | 需要排除的解释 |
| --- | --- | --- |
| 老品放量 | 相同商品 ID 的同窗日销售增长 | 上架重复、链接迁移、单日事件 |
| 新品拉动 | 上架时间与上市后销售证据、可比店铺总量 | 用本期榜单遗漏老品下降 |
| 达人扩张 | 新增/活跃达人证据及其对应商品/内容表现 | 名单只是累计数；达人先增长还是销售先增长不清楚 |
| 内容增长 | 可比内容发布/表现变化与商品关联 | 播放来自付费、视频年龄不同、热度未转销售 |
| 广告加码 | 同期日投入估算、归因指标和总量变化 | 归因重叠、延迟、同日促销或价格变化 |
| 类目上涨 | 同市场类目在相近周期同向变化 | 类目层级或时间不匹配 |

以上是关联证据。只有足够可比、排除替代解释或有实验支持时才能升级因果语言。不同维度可能解释同一笔销售，不累加它们的“贡献”。

## 4. 评估用户可做的动作

每个候选动作写出：证据 → 可借鉴机制 → 用户所需条件 → 最小测试 → 主指标与检查时间 → 停止/扩大条件。

用户没有独家货源、达人资源、预算或制作能力信息时列为条件，不假设与竞店同等资源。默认输出 3 个优先动作，用证据强度、执行成本和可验证性排序；不根据竞店销售额预测用户收益。
