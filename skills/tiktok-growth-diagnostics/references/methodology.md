# 从指标变化到可验证解释

## 1. 先验证异动是否成立

记录指标定义、主体、市场、币种、窗口、源时区、抓取时刻和实际数据截止。检查重复/缺失日期、未完整日、累计/日值错用、回补和上下游口径冲突。

若本期少一天，不能补零后宣布下降，也不将完整周与 6 天总量直接比较；优先补齐或选择两个完整可比窗口。用日均对比只能作为另一种明确口径，不能冒充周 GMV 环比。

指标有效时计算：

- `ΔM = M1 - M0`；当 `M0 > 0` 时，变化率为 `ΔM / M0`。
- 基期为零只报“由 0 到 M1”及差值；零与缺失分开。
- 同时查看日序列、同星期结构和单日峰值影响。历史不足时不声称已控制季节性或统计显著异常；阈值由用户业务目标或明确标注的探索规则给出。
- 同一个滚动时间窗在不同采集时点会变化，不把这种移动窗口差异当成数据修订。

## 2. GMV 的数量与单位金额拆分

仅在 GMV 与销量同口径、两期销量均大于零时，令 `Q` 为销量，`P = GMV / Q` 为单位成交金额，则 `G = Q × P`。

使用对称分解，避免把交互项任意归给一侧：

```text
数量项 = (Q1 - Q0) × (P0 + P1) / 2
单位金额项 = (P1 - P0) × (Q0 + Q1) / 2
数量项 + 单位金额项 = G1 - G0
```

例：基期 GMV=1000、销量=100，本期 GMV=900、销量=100，变化 -100 全部在单位金额项。它可能来自价格、折扣或商品组合，不证明卖家降价。先检查具体商品/SKU 才能进一步区分。

销量为零或缺失时，不定义不存在的单位金额；报告总额/数量变化并跳过此分解。没有订单数不计算 AOV，没有可比流量/转化分母不套用流量×转化×客单价模型。

## 3. 单一维度贡献与对账

选择有历史支持、分项可互斥的一个维度：如商品 ID 或源明确互斥的渠道。独立分析其他维度，不把商品、达人、视频与广告放进同一个加法分解。

对每个有两期值的分项计算 `Δ_i = M_i1 - M_i0`，并列总变化与 `未解释差额 = 总变化 - ΣΔ_i`。差额可能包含未覆盖实体、下架商品、估算或口径差异，不直接冠以某个原因。

- 分项候选尽量合并基期与本期重要商品，避免本期榜单遗漏消失的历史主力。
- 缺失分项值不补零；确认某商品该期尚未存在且口径支持零值时才可记录真实零。
- 增长贡献百分点为 `100 × Δ_i / M0`，基期总额为正才算。净变化贡献比例 `Δ_i / ΔM` 在变化近零时不报；有抵消时可为负或大于 100%。
- 示例：总额 100→90，A 为 60→40、B 为 40→50。A 变化 -20，B +10，合计 -10。A 占净下降 200%，B 抵消 100%，不能裁剪成加总 100% 的饼图。
- 若只有 A 的可比历史，则报告 A -20、未解释差额 +10，不能认定 B 的贡献已知。
- 做对账时使用未舍入值，并声明显示舍入/估算误差；不要为了加总相等修改源数据。

## 4. 假设分级

| 状态 | 所需证据 | 推荐措辞 |
| --- | --- | --- |
| 已核实的数值变化 | 可比两期值和对账 | “商品 A 的 GMV 减少 X” |
| 有支持的机制假设 | 时间顺序与关联实体证据、替代解释检查 | “达人活动变化与下降同步，值得优先验证” |
| 未验证原因 | 只有间接线索或缺少后台数据 | “缺货尚无直接证据，需要 SKU 库存事件” |
| 不支持/有反证 | 可比数据与假设预测相反 | “现有数据不支持投放减少这一解释” |

算术贡献只解释数值从哪部分变化，不解释为什么变。时间先后是因果必要线索之一，不能单独证明原因。

根据数据选择竞争假设。例如销量下降同时视频播放下降，检查同视频/同商品关联、付费变化及视频年龄；不要直接宣布平台限流。达人当期缺席也可能是统计窗、榜单截断或身份映射问题。

## 5. 排查与行动排序

每条排查项写明影响规模、证据状态、最小需要的数据、具体检查、支持/否定条件和下一检查时间。优先做影响大且验证便宜的检查；没有可靠影响量时不伪造量化排序。

区分可立即做的低成本验证与依赖根因成立的经营调整。未证明缺货不要求补货，未证明投放问题不建议大幅削减预算。所有必要数据不可得时交付“已确认变化 + 未解释范围 + 最小补数”，不硬填单一根因。
