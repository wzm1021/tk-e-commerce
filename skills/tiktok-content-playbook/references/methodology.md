# 内容编码、原创脚本与实验

## 证据分层

为每个样本记录 `video_id`、关联商品、发布时间、指标期、广告状态、脚本来源和可见媒介。

- `字幕观察`：实际文字、时间戳、卖点出现顺序、口头 CTA。
- `视觉观察`：实际看到的演示动作、场景、镜头、屏幕文字，带时间点或帧证据。
- `机制推断`：为什么可能减少疑虑或吸引注意，有对应观察但不是因果结论。
- `创作建议`：为新脚本设计的画面和表达，不能归入竞品事实。

字幕时间戳表示台词位置，不能证明留存变化。来自描述的文字不赋造时间戳。字幕语言、翻译和错词影响理解时保留原文并标注。

## 编码维度

| 维度 | 记录内容 |
| --- | --- |
| 开场 | 问题、结果展示、反差或场景引入；引用必要短片段 |
| 受众与场景 | 谁在什么情境下需要这个商品；区别明说和推断 |
| 痛点/欲望 | 具体问题以及出现位置 |
| 核心卖点 | 功能、便利、体验或价值主张；区分来源声明与已验证事实 |
| 演示/证明 | 口述证据与实际可见演示分别记录 |
| 异议处理 | 尺寸、适配、使用难度、价格等疑问如何被回答 |
| 优惠/CTA | 原视频声称的优惠和行动引导；不沿用过期优惠 |

不用“万能爆款结构”强行补齐所有维度；缺少 CTA 或演示本身也可能是观察结果。

## 比较方法

优先控制同商品、同市场/语言、接近发布时间和视频年龄、相似达人量级及付费状态。目标是找可测试差异，样本不足以控制这些因素时列出混杂。

- 有同窗销售与播放数据时，可报每千次播放对应 GMV `1000 × GMV / plays`，须说明范围和归因；播放为零或时期不一致不算。
- 互动率仅沿用源定义，或明确采用的互动项及分母。视频互动日趋势不能作为日订单趋势。
- 商品关联多、样本播放高、被持续投放均不证明脚本促进购买；检查普通/较弱样本是否也具有同样元素。
- 不从少量选中视频给元素打“提升 X%”效果标签。跨样本重复且有对照支持时写“优先测试假设”，而非“已验证最佳模板”。

## 生成原创脚本

从商品可确认事实和受众问题出发，借鉴抽象的信息组织方式，重新写措辞与场景。每个版本应包含：目标受众、单一主张、开场、展开、演示建议、异议处理、CTA。

将尚未确认的性能、认证、对比、价格和优惠列入制作前核验项，不把它们写成可直接发布的确定陈述。没有真实体验素材时不用伪造第一人称用户评价。

默认 3 个方向分别形成不同假设；若要直接 A/B 比较，应从一个方向生成只改变一个变量的 A/B 两版，其他条件固定。3 个方向同时改变多个要素只能用于探索，不能当单变量实验。

## 实验设计

- 写出假设、变量、固定条件、受众、分配方式、主指标、观察窗口、停止条件和需要记录的字段。
- 自然发布难以随机分配流量，使用匹配发布时间/达人/商品及重复批次；报告为方向性证据，不称随机实验。
- 有用户提供的随机广告实验数据时，再做随机实验判断；不暗自创建广告或预算。
- 主指标随目标选取：关注吸引力可用真实后台留存，关注行动可用真实点击率，关注成交可用同口径订单/销售数据。不可得时列为执行后需采集项，选择当前可见的代理指标并说明局限。
- 检查日和样本要求按用户业务基线或明确假设预先设置。缺少方差/基线时不承诺固定样本量足够，不反复偷看后宣布显著胜出。
- 判定保留 `支持/不支持/证据不足` 三种结果，不强行挑赢家。
