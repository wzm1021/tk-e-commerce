# 自行部署

本目录提供 systemd、容器网络、备份和版本清理模板。模板中的主机名、地址、证书、路径和账号需要按自己的环境配置，不附带原托管服务的基础设施或凭据。

发布前核对目标服务器当前版本与本地差异，构建并执行相应测试。静态更新先上传带哈希资源，再原子替换入口 HTML；服务端及执行器更新使用新的发行目录，在安全维护窗口切换，先等待在途任务结束。Agent 逻辑修改需要重建镜像。

前端验收覆盖用户端、管理员入口、登录前后、电脑与手机布局；后端变更还需验证业务、租户授权与用量结算。正式线上验收通过后，按自行确定的保留策略清理旧版本，保护业务数据和仍在使用的文件。

`prune-releases.py` 会删除旧发行目录及未使用的旧 Agent 镜像。部署者必须先阅读脚本、适配目录和保留策略，不能将示例直接指向未知服务器。数据备份和恢复应独立验证。

数据库迁移通过 `npm run migrate` 执行；初始化通过 `npm run bootstrap` 从私密 stdin 接收配置。应用使用受限数据库角色，测试使用隔离数据库。生产凭据、主密钥和 Worker 令牌保存在仓库外。
